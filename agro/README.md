## 📌 Sobre o Projeto

**AgroSystem** é um sistema de gerenciamento para atividades agrícolas, financeiro e produção agrícola. O objetivo é fornecer uma ferramenta intuitiva e eficiente para o controle da gestão agrícola.

## 🚀 Tecnologias Utilizadas

- **Java Web** (Java 23, Maven)
- **Front-end:** JavaScript, JSP, Bootstrap 4
- **Arquitetura:** MVC
- **Banco de Dados:** PostgreSQL 17
- **IDE:** NetBeans 24
- **Servidor:** Apache Tomcat 10.1.28

## 🛠️ Como Configurar e Executar

### 1️⃣ Clonar o Repositório
```bash
git clone 
cd agro
```

### 2️⃣ Configurar o Banco de Dados (PostgreSQL)
1. Criar um banco de dados:
   ```sql
   CREATE DATABASE agro;
   
   ```


### 3️⃣ Compilar e Executar o Projeto
```bash
mvn clean install
mvn tomcat7:run
```

O sistema estará disponível em: **http://localhost:8080/AgroSystem**
